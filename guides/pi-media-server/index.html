Turn a Raspberry Pi into a home media server

Set up Jellyfin for music and video around the house.

Start with files you already have

A media server organises your own music and video and makes them available to compatible devices on your home network. Use files you have permission to store and play. Jellyfin provides the server software and apps for browsing your library.

Choose a small, realistic project

A Raspberry Pi can be a learning project for serving files that your player can play directly. Jellyfin’s hardware guidance warns that Raspberry Pi boards are a poor choice when video needs converting during playback. For a dependable multi-user video server, consider a suitable mini PC instead.

Get the hardware ready

Use stable power, a case with ventilation and storage large enough for your files. Prefer Ethernet for the server. A microSD can hold the operating system; a separate USB drive can hold the media, with another copy kept elsewhere.

Install and add your library

Install a supported 64-bit operating system and follow Jellyfin’s current installation instructions for that system. Open the setup wizard on your home network, create your administrator account and add your media folders. Give the server permission to read those folders and use the recommended naming for films and TV series.

Test from your actual player

Try one file from a phone, computer or TV app before copying a whole collection. Check the playback information to see whether it is playing directly or converting the file. If playback stutters, try a file format supported by the player or use a more capable server.

Keep the first setup local

Start with access inside your home, keep the software updated and record how you set it up. Keep a separate copy of irreplaceable media. Once the local setup works, you can decide whether you need anything more.
