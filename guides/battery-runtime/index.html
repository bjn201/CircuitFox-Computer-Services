How to estimate portable power station runtime

Plan battery capacity around the devices you actually need.

Start with the load

Write down each device’s average power in watts. A charger’s maximum rating is not the same as the device’s continuous consumption. Measure the equipment in normal use where possible, and add the loads that will run at the same time.

Use watt-hours

A planning estimate is capacity in Wh × usable fraction ÷ average load in W. For example, a hypothetical 1,000Wh battery with 80% usable energy and a 100W load gives eight hours. The 80% figure is an assumption, not a measured specification.

Allow for real conditions

Inverter overhead, battery age, temperature and fluctuating demand change the result. Low-power equipment can be particularly affected by standby consumption. Check continuous output and startup demand separately: enough stored energy does not guarantee that a device can start.

Test your plan

Run the intended equipment before relying on it. Record the starting charge, load and duration, and keep a reserve rather than planning to empty the battery. Use our runtime calculator to compare scenarios, then replace assumptions with your measurements.
