Raspberry Pi 4: a small computer with plenty to learn

What it is, where it fits, and what you need before your first project.

What is it?

A Raspberry Pi 4 is a small single-board computer. The board includes USB ports, Ethernet and wireless networking; you add storage, power and the accessories your project needs.

Who is it for?

Our view: it makes most sense when you have a project in mind and enjoy learning as you go. A retro games box, music library or first coding project gives you a useful starting point. It is less appealing if you simply want a finished computer with nothing to configure.

Board, kit or finished setup?

A board alone is only the starting point. Make a checklist for the power supply, microSD card, case and display connections before comparing bundles. If you already own accessories, check their compatibility rather than buying everything twice.

Your first evening with it

  1. Pick one project and an operating system suited to it.
  2. Install the operating system on a microSD card using Raspberry Pi Imager.
  3. Connect the display and input devices, then follow the first-start setup.
  4. Install updates and keep a copy of your working configuration.

The compromises

Our advice is to keep the first project small. Leave demanding desktop work to your main PC and add complexity once the basic setup is reliable. Budget time for configuration as well as money for the board.
